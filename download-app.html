    How To Install On Android

    1. Download the APK using the button above.
    2. Open the downloaded APK file — usually from your Downloads folder or your browser's download notification.
    3. If Android asks for permission to install from this source, allow it for the browser or file manager you're using. This is a one-time permission for that app.
    4. Tap Install.
    5. Once installation finishes, open Aashir Portfolio from your home screen or app drawer.

    Security note: only install APK files from sources you trust. This APK is built directly from this website's own code with no third-party additions — but as with any APK installed outside the Play Store, Android will always ask you to confirm the "install from this source" permission first.

    Index — III

    How To Install / Run On Windows

    This build is a portable app, not an installer — there's nothing to "install," you just unzip and run it.

    1. Download the Windows app using the button above — it downloads a .zip file.
    2. Right-click the downloaded .zip and choose Extract All (or use your usual unzip tool) to a folder you'll keep, e.g. your Desktop.
    3. If Windows SmartScreen shows a blue "Windows protected your PC" warning, this is normal for apps that aren't yet code-signed with a paid certificate. Click More info, check that the app name reads AASHIR-Portfolio.exe, and click Run anyway — only do this if you trust the source you downloaded it from.
    4. Open the extracted folder and double-click AASHIR-Portfolio.exe to launch it. Keep the .exe inside its folder — it needs the other files next to it to run.
    5. Optional: right-click AASHIR-Portfolio.exe → Send to → Desktop (create shortcut) so you can launch it later without reopening the folder.

    Security note: only run downloaded .exe files from sources you trust, and keep the SmartScreen warning in mind — it appears for any new, unsigned app, not just this one.

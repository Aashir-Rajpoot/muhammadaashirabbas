Aashir Expense Tracker

A private, offline-first personal finance tracker created and published by Muhammad Aashir Abbas (Aashir Rajpoot).

Aashir Expense Tracker lets you log income and expenses, browse a monthly dashboard and category breakdown, and export or import your data as JSON. Every transaction stays on your own device — nothing is uploaded to a server.

Index — Features

Features

  • 01Log income and expenses across preset categories such as Food, Transport, Bills, Salary and Freelance.
  • 02Monthly dashboard with balance, income, expenses and a savings-rate indicator.
  • 03Category breakdown chart and a monthly income-vs-expense overview.
  • 04Search, filter and sort transactions by type, date range and category.
  • 05Export and import all data as a JSON file.
  • 06Light and dark themes, with an adjustable display currency.
Index — Technologies

Technologies

Built with vanilla HTML, CSS and JavaScript — no framework. Data is persisted with the browser's localStorage, and the app is installable and works offline as a Progressive Web App (PWA) with a service worker.
